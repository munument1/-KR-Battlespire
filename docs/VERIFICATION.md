# 검증 범위

2026-10-14, 0.1.0-preview1. 이 문서는 실제 게임 전수 검증 완료를 주장하지 않는다.

## 번역 엔진과 데이터

- TXT.BSA 141멤버 / 4,016필드 적용, 나머지 52,147칸의 바이트와 탭·행 구조 보존 검사.
- RSC 272레코드 적용, 입력 별칭·구획·센티넬·제어 접미부 보존 검사.
- 10개 글꼴에 필요한 한글 1,126자가 모두 비어 있지 않은 글리프로 존재.
- 이름 조회/어순 CPU 검사 6,954건 통과. 세 메모리 배치에서 UI 포인터 2,043곳 검사.
- 원래 x86 아이템 파서로 마법 정의 444개를 읽어 이름 뒤 수치·효과가 원본과 바이트 단위 일치.
- 줄바꿈 폭 CPU 검사 2,580건 및 원래 줄바꿈 루틴 90건, 글꼴 출력·폭 180건 통과.
- 엔진/아카이브 기존 단위 검사 26건 통과. LE 재배치 32,001개 보존.
- KA1T의 수정된 Steam 별도 대사와 VM3B 분기를 유지. VM3T의 별도 파일 우선순위 보완. ZN1T의 갈라진 시구 뒤 END/소환 명령 보존.

포르투갈어 참고 ZIP의 TXT 135파일은 파일명 기준 우리 번역 범위에 들어간다. 해당 ZIP에는 EXE/직업 템플릿이 없고 RSC 색인이 실제 문자열보다 2바이트 뒤를 가리킨다. 참고 파일을 실행하거나 배포에 복사하지 않았다. 영어 잔량을 파일명 비교만으로 0개라고 판정하지 않았다.

## 설치기

- 패키지의 파일 39개를 호환 원본에서 재구성하여 모든 목표 SHA-256 일치 확인.
- BSA 두 파일은 변경된 79/141개 항목에 각각 차분을 적용한 뒤 재조립.
- 원본 버전 불일치, 패치/백업 손상, 부분 설치, 설치 후 외부 변경 거부 검사.
- 설치·재설치·복원, 쓰기 실패 시 롤백, 경로 이탈 방지 합성 테스트.
- 실제 호환 원본 복사본과 배포용 실행 파일의 왕복 검사 결과는 `release_verification.json`에 기록한다.

합성 테스트와 게임 원본 복사본 검사는 설치된 파일의 정확성을 입증한다. 실제 게임의 모든 메시지창 폭·줄바꿈·스크롤·분기·퍼즐 동작을 입증하지 않는다. 화면 검증은 사용자 담당이며 Computer Use는 사용하지 않는다.
